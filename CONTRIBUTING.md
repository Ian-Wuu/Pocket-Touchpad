# Contributing / 参与贡献

## English

Bug reports, gesture compatibility reports, and focused improvements are welcome.

- Include iOS, macOS, and Xcode versions, device orientation, target Mac application, and relevant gesture settings.
- Describe expected behavior, actual behavior, and minimal reproduction steps. Remove pairing credentials and personal information from screenshots.
- For UI changes, include light/dark and portrait/landscape screenshots from an independent offline simulator.
- Run checks relevant to the change. Never inject mouse, keyboard, or desktop-switching input into a Mac in active use without the user's explicit permission.
- Prefer native frameworks and avoid unrelated refactoring or unnecessary dependencies.
- Update `docs/ThirdPartyNotices.txt` when adding third-party material.

By contributing, you confirm that you have the right to submit the material and agree to offer it under **Pocket Touchpad Source-Available License 1.0**. The license permits commercial work with the tool but prohibits commercializing the project's code or modified versions. Copyright assignment is not required. See the [licensing notice](docs/OPEN_SOURCE.md).

## 简体中文

欢迎提交故障复现、手势兼容性记录和范围明确的改进。

- 描述 iOS、macOS 与 Xcode 版本，以及横竖屏、目标 Mac 应用和相关手势设置。
- 说明预期行为、实际行为与最少复现步骤；移除截图中的配对凭据及个人信息。
- UI 改动附浅色、深色与横竖屏截图；使用独立离线模拟器截图。
- 完成与改动相关的编译或检查。未经使用者明确允许，不在其使用中的 Mac 上注入鼠标、键盘或桌面切换。
- 保持原生框架优先，避免无关重构与不必要依赖。
- 新增第三方来源时，同步更新 `docs/ThirdPartyNotices.txt`。
